Vous pouvez demander la suppression de votre compte MIKA sans désinstaller l’application.

1. Envoyer la demande

Écrivez à mickael.thermea.officiel@gmail.com, de préférence depuis l’adresse Google utilisée avec MIKA, avec l’objet « Suppression de mon compte MIKA ». Indiquez l’adresse concernée, sans joindre de documents ni votre code PIN.

L’éditeur vérifie la demande et supprime manuellement le compte d’authentification MIKA géré dans Supabase et les données de compte associées sous son contrôle, y compris les clés actives de récupération des sauvegardes. Sans ces clés, les anciennes archives peuvent devenir irrécupérables par Google ; conservez au préalable les copies et moyens de restauration nécessaires. Une confirmation vous est adressée. Le délai de réponse est en principe d’un mois, avec information si une prolongation légalement permise est nécessaire.

2. Retirer l’autorisation Google

Ouvrez les connexions de votre compte Google, sélectionnez MIKA et retirez son accès. Cette révocation et la suppression du compte MIKA sont deux actions distinctes. Le compte Google lui-même n’est pas supprimé.

3. Comprendre ce qui reste

  • Documents locaux : la demande distante ne supprime pas les fichiers de votre téléphone. Gérez-les dans MIKA ou dans les réglages Android, après avoir conservé ce dont vous avez besoin.
  • Exports : les fichiers partagés ou enregistrés ailleurs restent à ces emplacements.
  • Drive : les versions de test compatibles peuvent y enregistrer des archives chiffrées à votre demande. Supprimez les données MIKA dans les paramètres Google Drive, rubrique gestion des applications, si vous souhaitez aussi effacer ces archives. La suppression du compte Supabase ne les efface pas automatiquement.
  • Journaux et copies techniques : des traces limitées peuvent subsister selon les délais des prestataires ou une obligation légale.
Le mode local reste possible

Retirer l’association Google affichée dans MIKA ne supprime pas le compte serveur. Une suppression de compte ou une révocation Google ne fournit pas de nouveau moyen de récupérer un coffre dont le PIN est perdu.
