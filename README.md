# Site public MIKA

MIKA — Mobile Intelligent Keep & Archive.

Site statique pour GitHub Pages, sans dépendance JavaScript ni service payant.

Le contenu doit refléter la version Android effectivement disponible. Mettre à jour les pages confidentialité, conditions, suppression et aide avant d’activer une nouvelle fonction de sauvegarde ou de récupération.

Les éléments graphiques sont ceux du projet MIKA. Aucun secret ni document utilisateur ne doit être ajouté à ce dépôt.
